# CFEAR3-BFAR
## The latest CFEAR with BFAR fast-coded
CFEAR3-BFAR replaces the conservative k-strongest filter used in previous CFEAR versions with the BFAR (Bounded False Alarm Rate) detector, enhancing radar odometry estimation. This shift improves the system's ability to control false alarms while maintaining high accuracy in localization. By using the BFAR detector, CFEAR3 optimizes radar data processing for more reliable and efficient odometry, particularly in challenging environments.
The work is now published in the Springer Autonomous Robots journal [BFAR: improving radar odometry estimation using a bounded false alarm rate detector](https://link.springer.com/article/10.1007/s10514-024-10176-2) or
[arXiv](https://arxiv.org/abs/2109.09669)
